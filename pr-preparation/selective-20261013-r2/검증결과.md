# 검토 후 선택 파일 패치 r2

공식 최신 carrot-wip을 새 개발 clone에 받아 필요한 실행 파일19개(기존7 수정·추가12)만 선택 적용한다. 레이더14/PCM2/종방향3으로 나눴다. 기존 파일은 Toyota interface/radar_interface/carcontroller, cruise, MPC, planner, radarcan이다. decoder9파일과 MIT LICENSE는 최신 ARS 원문이며 임의 필터/회생 계수는 바꾸지 않았다.

현재 소스94ecc00c의 직접 결과는 receiver/native/PCM178통과, 정지 명령24통과, 레이더 복구 receiver/helper69통과·실제IPC2생략, 원형 신호 출력3통과다. 선택 도구는 Linux40·Windows40통과이며 root Linux40을 별도로 확인했다. 그룹은 서로 겹치므로 합산하지 않는다. 실제3로그는2,399정상레코드·367전달점·원형Float32차이0·B4checksum오류0/원본 제어OFF다.

626 기준 통합의 기존 upstream CPU·차간거리·신호153통과(기존NumPy68경고), Toyota CP74조건 허용외차이0, 원격 ARS 후보271통과·설치환경1생략 근거는 보존했다. 이번 변경이 없는 검사를 새 통과로 세지 않았다. native 검사는 기존6라이브러리의 별도 동결 사본을 사용했으며 새C/ARM 전체 빌드를 수행하지 않았다.

`실행파일_19개.csv`와 assets의3patch가 런타임 범위다. 전체 PR patch는 문서·시험·격리helper를 포함한34파일이다. 실제 최신 원격 다운로드/clone 적용 결과는 별도 `원격준비_검증.json`이 있을 때만 완료 근거로 사용한다. 미래 핵심 소스/문맥/guard가 달라지면 강제 적용하지 않는다.

[Carrot PR 비교](https://github.com/ajouatom/openpilot/compare/carrot-wip...Mlnege:codex/rav4-ars510-carrot-latest?expand=1)와 [ARS PR 비교](https://github.com/ds-sebastian/ars510-radar/compare/main...Mlnege:codex/carrot-native-ars510-dispatch?expand=1)에 후보를 준비했다. 실제 PR 제출은 하지 않았다. 사용 방법은 README에 있다.

ECU/펌웨어, PCS/AEB 유지, 회생제동 배분, Konik/ARM 전체 빌드, 실제 제동과 실행 마감은 미검증이다. 운영 설치/Params/실차CAN/제어 활성화/재부팅/안전 우회는 실행하지 않았다.

공개 r2 고정 태그의 실제 원격 준비를 직접 완료했다. 공식0611 HEAD를2번 확인하고 선택19본문·변경목록과15guard 일치/범위밖 변경0, 다운로드6파일 원바이트 동일을 확인했다. 고정 소스태그는 보존하고 이 후속 실행 근거는 검증 저장소 main과 최종 ZIP에 추가했다.
